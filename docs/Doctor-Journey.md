# Doctor Journey

1. Authenticate and redirect to the permitted clinical workspace.
2. Review assigned appointments and schedule.
3. Open only authorized/assigned patient context.
4. Record consultation findings.
5. Create prescription and optional lab order.
6. Review returned lab reports.
7. Complete the encounter and update follow-up instructions.
8. Manage availability and notifications.
9. Sign out.

The current repository has doctor management, availability, appointments, prescriptions, and lab structures. A dedicated complete doctor dashboard, radiology workflow, signed clinical notes, and live assigned-patient authorization tests require further work.
